<b>6. Description:</b> <br/>
This is my personal portfolio website, a single-page application (SPA) built from scratch using React and Vite. The goal was to create a clean, fast, and professional online presence that reflects who I am as a developer.
The website covers everything about me, my background, technical skills, work experience, personal and professional projects, and ways to get in touch. It is fully responsive across all devices and optimized for performance and SEO.

Key motivations behind building this:
<ul>
<li>Have a central place to showcase my work and skills</li>
<li>Demonstrate my frontend development capabilities</li>
<li>Make it easy for recruiters and collaborators to reach me</li>
<li>Keep it maintainable and easy to updated</li>
</ul>

<b>7. Features:</b><br/>
<ul>
<li><b>Fully Responsive</b> — works seamlessly on mobile, tablet, and desktop</li>
<li><b>Interactive Skills Section</b> — visual skill display</li>
<li><b>Timeline Experience</b> — clean timeline for work history and education</li>
<li><b>SEO Optimized — proper meta tags, Open Graph tags, and sitemap</li>
<li><b>Fast Load Times</b> — Vite-powered build with code splitting and lazy loading</li>
<li><b>Accessible</b> — semantic HTML, advanced CSS and 3d Map embeded</li>
</ul>
